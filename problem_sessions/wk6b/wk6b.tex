\noindent
You saw the following context-free grammars in class on Wednesday; in each example, the grammar itself is on the left; the explanation for each non-terminal is on the right.
\begin{itemize}
\item
Properly nested strings of parentheses. 
\begin{align*}
	S & \to \e\mid S \LP S \RP
		&& \text{properly nested parentheses}
\end{align*}
Here is a different grammar for the same language:
\begin{align*}
	S & \to \e\mid \LP S \RP \mid S S
		&& \text{properly nested parentheses}
\end{align*}

\item
$\set{\Sym0^m\Sym1^n\mid m\ne n}$.  This is the set of all binary strings composed of some number of \Sym0s followed by a \emph{different} number of \Sym1s.
\begin{align*}
	S & \to A \mid B
		&& \Setbar{\Sym0^m\Sym1^n}{m\ne n} \\
	A & \to \Sym0A \mid \Sym0C
		&& \Setbar{\Sym0^m\Sym1^n}{m > n} \\
	B & \to B\Sym1 \mid C\Sym1
		&& \Setbar{\Sym0^m\Sym1^n}{m < n} \\
	C & \to \e \mid \Sym0C\Sym1
		&& \Setbar{\Sym0^m\Sym1^n}{m = n}
\end{align*}
\end{itemize}
\hrule
\bigskip

\noindent
Give context-free grammars for each of the following languages over the alphabet $\Sigma = \set{\Sym0,\Sym1}$.  For each grammar, describe the language for each non-terminal, either in English or using mathematical notation,  as in the examples above.  We probably won't finish all of these during the lab session.


\begin{enumerate}
\itemsep 4ex
%----------------------------------------------------------------------

\item
All palindromes in $\Sigma^*$

\item
All palindromes in $\Sigma^*$ that contain an even number of \Sym1s

\item
All palindromes in $\Sigma^*$ that end with \Sym1

\item
All palindromes in $\Sigma^*$ whose length is divisible by $3$

\item
All palindromes in $\Sigma^*$ that do not contain the substring \Sym{00}

\end{enumerate}
