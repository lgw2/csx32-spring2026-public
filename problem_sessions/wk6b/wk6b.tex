\noindent
In class on Wednesday we saw the following context-free grammar. The grammar is
on the left; the explanation for the last non-terminal is on the right. In order to define
$L(S)$, let's first figure out what $L(A)$ and $L(B)$ are.
\begin{align*}
	S & \to A \mid B
		&& 
	\\
	A & \to \Sym0 A \mid \Sym0 C
		&&
	\\
	B & \to B \Sym1 \mid C \Sym1
		&&
	\\
	C & \to \e \mid \Sym0 C \Sym1
		&& \set{\Sym0^n\Sym1^n\mid n\ge 0}
\end{align*}

\bigskip

\begin{enumerate}
\itemsep 4ex
	\item What is $L(A)$?
	\item What is $L(B)$?
	\item What is $L(S)$?
\end{enumerate}

\hrule
\bigskip

\noindent
Give context-free grammars for each of the following languages over the alphabet
$\Sigma = \set{\Sym0,\Sym1}$.  For each grammar, describe the language for each
non-terminal, either in English or using mathematical notation,  as in the
examples above.  We probably won't finish all of these during the problem session.


\begin{enumerate}
	\setcounter{enumi}{3}
\itemsep 4ex
%----------------------------------------------------------------------

\item
All palindromes in $\Sigma^*$

\item
All palindromes in $\Sigma^*$ that contain an even number of \Sym1s

\item
All palindromes in $\Sigma^*$ that end with \Sym1

\item
All palindromes in $\Sigma^*$ whose length is divisible by $3$

\item
All palindromes in $\Sigma^*$ that do not contain the substring \Sym{00}

\end{enumerate}
