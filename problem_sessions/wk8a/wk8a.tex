Recall the proof that the halting problem is undecidable:

\begin{Solution}
   For the sake of contradiction, suppose there is a Turing machine $H$
   that decides the language \textsc{Halt} = $\{\langle M,w \rangle : M \text{ halts on input } w\}$.
   Now, we can decide the language \textsc{SelfHalt} = $\{\langle M \rangle : M
   \text{ halts on input } \langle M \rangle\}$ by running $H$ on input $\langle
   M, \langle M \rangle \rangle$. We now show that this method decides
   \textsc{SelfHalt} correctly by showing that it correctly accepts and rejects the appropriate inputs.

   \begin{itemize}
    \item If $M$ halts on $\langle M \rangle$, then $H$ accepts on input $\langle M, \langle M
    \rangle \rangle$, and so our method accepts on input $\langle M \rangle$.

    \item If $M$ does not halt on input $\langle M \rangle$, then $H$ rejects on
    input $\langle M, \langle M \rangle \rangle$, and so our method rejects on
    input $\langle M \rangle$.
   \end{itemize}

   




\end{Solution}
